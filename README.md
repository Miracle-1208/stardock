# StarDock｜星坞

一个面向大学生的 AI Course Workspace 前端原型。

> 一门课，一个长期存在的 AI 工作区。

[在线体验](https://stardock-learning-space.bdxtvbhvgy.chatgpt.site)

## 产品概念

StarDock 将课件、教材、笔记、作业、录音、往年试卷和课程通知组织在同一门课程下。AI 不从空白对话开始，而是持续结合课程资料、知识结构与学生的学习活动提供下一步行动。

核心循环：

```text
课程资料 → 课程理解 → 学习活动 → 学生状态 → AI 行动
```

## 已实现的原型交互

- 学期首页与多课程导航
- 可行动的概率论课程主页：继续学习、课程待办、最近资料、薄弱点行动与课程动态
- 跨课程每日计划，可新增任务、设置预计用时并记录完成进度
- 连续对话式课程 AI、资料引用与思考进度
- 统一课程资料库与模拟上传处理
- Notion 风格课程笔记
- 练习答错后同步更新课程地图、学习计划和 AI 提醒
- 期末考试复习模式与 AI 估计重点
- 跨课件、教材、作业、笔记和试卷的统一搜索
- 个人题册：跨课程收录题目、规范化展示题解与笔记，并连接再练、背诵和每日计划
- 跨课程背诵辅助：选择资料范围、生成并筛选题目、逐题回答、关键点诊断与遗漏追问
- 桌面端优先并支持窄屏布局

## 技术栈

- React 19
- TypeScript
- vinext / Vite
- Lucide React
- CSS 动画与响应式布局

所有课程数据和 AI 内容均为前端 Mock，不依赖真实后端或 LLM API。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建与检查：

```bash
npm run lint
npm run build
```

## 当前状态

这是一个用于产品验证与演示的高保真前端原型，不包含登录、数据库或真实文件上传。
