# StarDock｜星坞

一个面向大学课程的 Agent 学习资料工作台前端原型。

> 把零散资料整理成可审阅、可维护、可导出 LaTeX 的课程笔记，再围绕具体章节开展学习。

[在线体验](https://stardock-learning-space.bdxtvbhvgy.chatgpt.site)

## 产品概念

StarDock 将课件、教材、笔记、作业、录音、往年试卷和课程通知组织在同一门课程下。每门课程由两个边界清晰、持续连接的层构成：

- **共享课程舱**：由同校或跨校贡献者维护的课件、课程主笔记、资料索引、往年题与版本记录。
- **私人学习层**：每个学生独有的笔记、题册、学习计划、答题证据和 Agent 对话。

学生可以发现并 Fork 一个可靠的共享课程舱，再在不污染公共资料、不暴露个人学习记录的前提下形成自己的长期学习空间。Agent 由用户显式发起，负责检索、整理、生成和来源对照；产品不根据有限行为推断长期学习水平。

核心循环：

```text
发现课程舱 → Fork 共享结构 → 开展学习 → 积累私人记录 → Agent 提议下一步 → 用户确认行动
```

## 已实现的原型交互

- 学期首页与多课程导航
- 课程舱发现页：按学校、课程、教师、学期与类别搜索，并以资料覆盖、维护者凭据、版本记录和社区使用情况帮助判断
- 公共课程舱详情与完整 Fork 流程：选择学期、命名、连接上游版本，并明确私人数据边界
- 我的课程舱：统一管理个人创建与 Fork 的课程空间
- 共享课程层 / 私人学习层双层资料视图，支持查看原始课程舱与手动应用上游更新
- 贡献者工作台与发布流程：只公开明确选择的课程资产，题册、计划和 Agent 对话始终保持私密
- 个人资料、学校身份和课程成绩验证的展示流程
- 可行动的概率论课程主页：继续阅读、资料与笔记状态、课程待办和客观课程动态
- 可执行的跨课程每日计划：任务状态、25 分钟专注计时、完成总结、实际专注记录，以及题册、背诵辅助与课程待办联动
- 任务型课程 Agent：专题整理、资料检索、内容比较、章节练习生成和引用检查
- 统一课程资料库：上传只保存原始资料，并区分已入库、已索引和已整理状态
- Agent 笔记工作台：专题要求、参考资料检索与人工增删、草稿审阅和课程主笔记发布
- 课程主笔记的 PDF、`.tex` 与完整 LaTeX 工程包导出展示
- 笔记章节与练习、题册、背诵辅助和每日计划之间的学习动作关联
- 章节练习的本题结果、提示使用记录，以及由用户主动选择的题册、计划和再做入口；答错后的客观证据会进入私人层并触发 Agent 的可执行建议
- 基于用户确认资料的模拟试卷与可追溯复习材料索引
- 跨课件、教材、作业、笔记和试卷的统一搜索
- 个人题册：跨课程收录题目、规范化展示题解与笔记，并连接再练、背诵和每日计划
- 跨课程背诵辅助：选择资料范围、生成并筛选题目、逐题回答、本轮关键点对照与题目级重背状态
- 桌面端优先并支持窄屏布局

## 技术栈

- React 19
- TypeScript
- vinext / Vite
- Lucide React
- CSS 动画与响应式布局

所有课程数据和 Agent 内容均为前端 Mock，不依赖真实后端或 LLM API。页面只展示资料状态、笔记版本、任务执行、答题结果、提示使用和本轮关键点覆盖等可直接验证的状态。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建与检查：

```bash
npm run lint
npm run build
```

这是一个用于产品验证与演示的高保真前端原型，不包含登录、数据库或真实文件上传。
